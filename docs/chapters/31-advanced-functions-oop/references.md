# Riferimenti: Funzioni Avanzate e OOP

1. **Lambda (programming)** — Wikipedia
   [https://en.wikipedia.org/wiki/Anonymous_function](https://en.wikipedia.org/wiki/Anonymous_function)
   Spiega le funzioni anonime (lambda) in tutti i linguaggi di programmazione, inclusa la parola chiave `lambda` di Python, con esempi che mostrano come le funzioni brevi e inline vengono definite e usate senza un nome.

2. **Closure (computer programming)** — Wikipedia
   [https://en.wikipedia.org/wiki/Closure_(computer_programming)](https://en.wikipedia.org/wiki/Closure_(computer_programming))
   Descrive come le closure catturano le variabili da uno scope racchiudente, un concetto chiave quando si scrivono funzioni factory e decorator nel modello di funzioni avanzate di Python.

3. **Decorator pattern** — Wikipedia
   [https://en.wikipedia.org/wiki/Decorator_pattern](https://en.wikipedia.org/wiki/Decorator_pattern)
   Copre il pattern di design software che la sintassi `@decorator` di Python implementa, spiegando come racchiudere funzioni o classi aggiunge comportamento senza modificare il codice sorgente originale.

4. **Python Crash Course** (2ª ed.) di Eric Matthes — No Starch Press, 2019.
   Il Capitolo 9 copre le classi, l'eredità, e le istanze in uno stile chiaro e adatto ai principianti che collega il divario tra le semplici funzioni e i programmi orientati agli oggetti completi.

5. **Learning Python** (5ª ed.) di Mark Lutz — O'Reilly Media, 2013.
   Un riferimento esaustivo che copre le espressioni lambda, le closure, i decorator, e l'intero modello OOP di Python incluse le classi base abstract, ideale per studenti pronti ad andare più in profondità.

6. **Python Docs — Functional Programming HOWTO**
   [https://docs.python.org/3/howto/functional.html](https://docs.python.org/3/howto/functional.html)
   La guida ufficiale di Python agli strumenti di programmazione funzionale incluso `lambda`, `map`, `filter`, e le closure, con spiegazioni chiare ed esempi provabili direttamente rilevanti per questo capitolo.

7. **Python Docs — Classes (Tutorial)**
   [https://docs.python.org/3/tutorial/classes.html](https://docs.python.org/3/tutorial/classes.html)
   La sezione del tutorial autorevole sulle classi Python che copre l'eredità, la sovrascrittura dei metodi, e il polimorfismo — esattamente i concetti OOP che gli studenti incontrano in questo capitolo.

8. **Real Python — Python Decorators 101**
   [https://realpython.com/primer-on-python-decorators/](https://realpython.com/primer-on-python-decorators/)
   Un percorso passo passo su come funzionano i decorator Python, partendo dalle funzioni di prima classe e dalle closure e costruendo fino alla sintassi `@`, perfetto per studenti che incontrano i decorator per la prima volta.

9. **Programiz — Python Inheritance**
   [https://www.programiz.com/python-programming/inheritance](https://www.programiz.com/python-programming/inheritance)
   Esempi interattivi che mostrano l'eredità singola e multipla, l'ordine di risoluzione dei metodi, e la funzione `super()`, supportando gli argomenti di eredità e polimorfismo di questo capitolo.

10. **W3Schools — Python Lambda**
    [https://www.w3schools.com/python/python_lambda.asp](https://www.w3schools.com/python/python_lambda.asp)
    Un riferimento conciso e adatto ai principianti con esempi Try-It-Yourself che mostrano come scrivere e usare le funzioni `lambda` nell'ordinamento, nel filtraggio, e nelle brevi espressioni funzionali.
