# Riferimenti: Input e Output su File

1. **Wikipedia: Computer File** — [https://en.wikipedia.org/wiki/Computer_file](https://en.wikipedia.org/wiki/Computer_file)
   Spiega cos'è un file del computer, come i dati vengono memorizzati sul disco, e la differenza tra file di testo e binari. Fornisce il contesto essenziale per capire perché i programmi Python leggono e scrivono file.

2. **Wikipedia: File System** — [https://en.wikipedia.org/wiki/File_system](https://en.wikipedia.org/wiki/File_system)
   Copre come i sistemi operativi organizzano i file in directory, come funzionano i percorsi dei file, e la differenza tra percorsi assoluti e relativi — tutto direttamente rilevante per localizzare i file nei programmi Python.

3. **Wikipedia: Input/Output** — [https://en.wikipedia.org/wiki/Input/output](https://en.wikipedia.org/wiki/Input/output)
   Descrive il concetto di input e output nell'informatica, incluso come i programmi comunicano con i dispositivi di memorizzazione. Aiuta gli studenti a capire perché l'I/O su file è una competenza di programmazione fondamentale.

4. **Python Crash Course** di Eric Matthes (No Starch Press)
   Il Capitolo 10 dedica un'intera sezione alla lettura e scrittura di file usando `open()`, l'istruzione `with`, e le modalità comuni dei file — perfettamente allineato agli argomenti centrali di questo capitolo per i principianti.

5. **Automate the Boring Stuff with Python** di Al Sweigart (No Starch Press; gratuito online su automatetheboringstuff.com)
   I capitoli sulla gestione di file e percorsi mostrano usi pratici e del mondo reale della lettura e scrittura di file di testo, rendendo i concetti astratti di I/O immediatamente utili e motivanti per i giovani studenti.

6. **Python Official Docs: Reading and Writing Files** — [https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files)
   La sezione autorevole del tutorial ufficiale di Python su `open()`, le modalità dei file, `read()`, `write()`, e l'istruzione `with`. Precisa, aggiornata, e scritta dagli stessi creatori del linguaggio.

7. **Real Python: Reading and Writing Files in Python** — [https://realpython.com/read-write-files-python/](https://realpython.com/read-write-files-python/)
   Una guida approfondita e adatta ai principianti che copre `open()`, le modalità dei file, `read()`, `readline()`, `write()`, e l'istruzione `with` con esempi chiari e spiegazioni delle insidie comuni.

8. **W3Schools: Python File Handling** — [https://www.w3schools.com/python/python_file_handling.asp](https://www.w3schools.com/python/python_file_handling.asp)
   Fornisce esempi concisi e interattivi di apertura, lettura, scrittura, e chiusura dei file in Python. L'editor try-it-yourself permette agli studenti di sperimentare le operazioni sui file direttamente nel browser.

9. **Programiz: Python File I/O** — [https://www.programiz.com/python-programming/file-operation](https://www.programiz.com/python-programming/file-operation)
   Spiegazioni passo passo delle modalità dei file, `open()`, `read()`, `readline()`, `write()`, e l'istruzione `with`, con esempi provabili ben adatti a studenti nuovi ai concetti di gestione dei file.

10. **GeeksforGeeks: Python File Handling** — [https://www.geeksforgeeks.org/file-handling-python/](https://www.geeksforgeeks.org/file-handling-python/)
    Copre il ciclo di vita completo delle operazioni sui file in Python — apertura, lettura, scrittura, aggiunta, e chiusura — con tabelle delle modalità ed esempi lavorati utili per rivedere e rafforzare i concetti del capitolo.
