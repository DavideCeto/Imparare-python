# Riferimenti: Prendere Decisioni con If/Else

1. **Conditional (computer programming)** — Wikipedia
   [https://en.wikipedia.org/wiki/Conditional_(computer_programming)](https://en.wikipedia.org/wiki/Conditional_(computer_programming))
   Spiega il concetto di esecuzione condizionale nella programmazione, coprendo la logica di diramazione if/else, i valori di verità, e come le strutture decisionali appaiono in molti linguaggi di programmazione incluso Python.

2. **Boolean algebra** — Wikipedia
   [https://en.wikipedia.org/wiki/Boolean_algebra](https://en.wikipedia.org/wiki/Boolean_algebra)
   Copre le basi matematiche della logica Vero/Falso che sta dietro a tutte le espressioni booleane di Python, gli operatori di confronto, e le condizioni usate dentro le istruzioni if ed elif.

3. **Relational operator** — Wikipedia
   [https://en.wikipedia.org/wiki/Relational_operator](https://en.wikipedia.org/wiki/Relational_operator)
   Descrive gli operatori di confronto (`==`, `!=`, `<`, `>`, `<=`, `>=`) usati per formare espressioni booleane in Python, spiegando come ogni operatore valuta due valori e restituisce True o False.

4. **Python Crash Course** di Eric Matthes (No Starch Press, 3ª ed.)
   Il Capitolo 5 copre le istruzioni if, gli operatori di confronto, e le catene elif/else con esempi chiari e adatti ai principianti che corrispondono direttamente ai concetti decisionali introdotti in questo capitolo.

5. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Scritto specificamente per giovani studenti, questo libro introduce le istruzioni if/else con esempi giocosi e spiegazioni visive ideali per studenti dai 10 ai 13 anni che compiono il salto da Scratch a Python.

6. **Python `if` Statement — Official Python Tutorial**
   [https://docs.python.org/3/tutorial/controlflow.html#if-statements](https://docs.python.org/3/tutorial/controlflow.html#if-statements)
   La documentazione autorevole di Python sulla sintassi di if, elif ed else, con esempi concisi che mostrano come Python valuta le condizioni e scegli quale blocco di codice eseguire.

7. **Python Conditions and If Statements — W3Schools**
   [https://www.w3schools.com/python/python_conditions.asp](https://www.w3schools.com/python/python_conditions.asp)
   Fornisce esempi interattivi e provabili di istruzioni if, elif ed else insieme a tutti gli operatori di confronto e logici di Python, rendendolo un eccellente riferimento rapido per i nuovi studenti.

8. **Python if...else Statement — Programiz**
   [https://www.programiz.com/python-programming/if-elif-else](https://www.programiz.com/python-programming/if-elif-else)
   Tutorial passo passo che copre le strutture if, if…else, e if…elif…else con diagrammi di flusso che mostrano visivamente come Python si dirama tra diverse condizioni, ideale per studenti visivi.

9. **Python if, else, elif Conditions — Real Python**
   [https://realpython.com/python-conditional-statements/](https://realpython.com/python-conditional-statements/)
   Guida approfondita alle istruzioni condizionali di Python che copre il contesto booleano, gli operatori di confronto, gli operatori logici, e le istruzioni if annidate, con esempi pratici per costruire una comprensione solida.

10. **Python Conditionals — Khan Academy**
    [https://www.khanacademy.org/computing/intro-to-python-fundamentals](https://www.khanacademy.org/computing/intro-to-python-fundamentals)
    Lezioni video ed esercizi di codifica adatti ai principianti che introducono la logica condizionale in Python, pensati per studenti senza esperienza di programmazione precedente oltre a strumenti a blocchi come Scratch.
