# Riferimenti: NumPy e Calcolo Scientifico

1. **NumPy** — Wikipedia
   [https://en.wikipedia.org/wiki/NumPy](https://en.wikipedia.org/wiki/NumPy)
   Copre la storia, il design, e le capacità della libreria NumPy, incluso il suo oggetto array n-dimensionale e le funzioni matematiche usate in tutta la programmazione Python scientifica.

2. **Array data structure** — Wikipedia
   [https://en.wikipedia.org/wiki/Array_(data_structure)](https://en.wikipedia.org/wiki/Array_(data_structure))
   Spiega cosa sono gli array, come memorizzano gli elementi in memoria contigua, e perché permettono operazioni matematiche rapide — conoscenza fondamentale per capire gli array NumPy.

3. **Scientific computing** — Wikipedia
   [https://en.wikipedia.org/wiki/Computational_science](https://en.wikipedia.org/wiki/Computational_science)
   Introduce il campo della scienza computazionale, mostrando perché esistono strumenti come NumPy e come Python è diventato un linguaggio leader per l'analisi dei dati scientifici e la simulazione.

4. **Python Crash Course** di Eric Matthes (No Starch Press)
   Fornisce un'introduzione adatta ai principianti alle liste Python e alle strutture di dati che serve come preparazione diretta per capire gli array NumPy e la loro notazione di slicing.

5. **Think Python** di Allen B. Downey (O'Reilly, gratuito online su greenteapress.com/wp/think-python-2e/)
   Enfatizza il pensiero matematico e la risoluzione algoritmica dei problemi, dando agli studenti le basi concettuali di cui hanno bisogno per applicare le funzioni NumPy a veri problemi scientifici.

6. **NumPy Quickstart Tutorial** — Documentazione Ufficiale di NumPy
   [https://numpy.org/doc/stable/user/quickstart.html](https://numpy.org/doc/stable/user/quickstart.html)
   La guida ufficiale per principianti a NumPy che copre la creazione degli array, l'indicizzazione, lo slicing, il reshaping, e il broadcasting — corrisponde direttamente a ogni argomento principale di questo capitolo.

7. **Python Lists and Arrays** — W3Schools
   [https://www.w3schools.com/python/python_lists.asp](https://www.w3schools.com/python/python_lists.asp)
   Spiega le liste Python con esempi interattivi; capire le liste built-in è un contesto essenziale prima di imparare come gli array NumPy le estendono e le migliorano.

8. **NumPy Arrays in Python** — GeeksforGeeks
   [https://www.geeksforgeeks.org/python-numpy/](https://www.geeksforgeeks.org/python-numpy/)
   Un riferimento completo con esempi di codice che copre la creazione degli array NumPy, le operazioni, lo slicing, e le funzioni matematiche — utile per cercare sintassi specifiche mentre si lavora sugli esercizi.

9. **NumPy Tutorial for Beginners** — Real Python
   [https://realpython.com/numpy-tutorial/](https://realpython.com/numpy-tutorial/)
   Un tutorial passo passo che spiega gli array NumPy, il broadcasting, e le operazioni vettorializzate con esempi chiari pensati per studenti Python nuovi al calcolo scientifico.

10. **NumPy Arrays** — Programiz
    [https://www.programiz.com/python-programming/numpy/array](https://www.programiz.com/python-programming/numpy/array)
    Spiegazioni adatte ai principianti su come creare e manipolare gli array NumPy, con esempi provabili e descrizioni semplici ben adatte a studenti dai 10 ai 13 anni che esplorano il Python scientifico.
