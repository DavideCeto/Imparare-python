# Riferimenti: Altri Booleani e Condizionali

1. [Boolean algebra](https://en.wikipedia.org/wiki/Boolean_algebra) - Wikipedia - Trattazione completa dei fondamenti dell'algebra booleana incluse le operazioni AND, OR, e NOT, le tavole di verità, e le equivalenze logiche che formano la base matematica delle espressioni booleane di Python.

2. [Boolean data type](https://en.wikipedia.org/wiki/Boolean_data_type) - Wikipedia - Spiega il tipo di dato booleano nei linguaggi di programmazione, incluso come Python rappresenta True e False, e come i booleani vengono usati nella logica condizionale e nei confronti.

3. [Truth table](https://en.wikipedia.org/wiki/Truth_table) - Wikipedia - Riferimento dettagliato per le tavole di verità che copre tutte le combinazioni degli operatori logici (AND, OR, NOT, XOR), supportando direttamente gli esercizi sulle tavole di verità introdotti in questo capitolo.

4. Python Crash Course (3ª edizione) - Eric Matthes - No Starch Press - Il Capitolo 5 copre le istruzioni if, le espressioni booleane, e le condizioni composte usando and/or/not, con esempi pratici ben adatti ai principianti nella fascia di età 10-13 anni.

5. Python for Kids - Jason R. Briggs - No Starch Press - Introduce i valori booleani e la logica condizionale con spiegazioni chiare e adatte all'età e brevi attività di codifica che rafforzano il ragionamento True/False e le istruzioni if con condizioni multiple.

6. [Python Boolean Values](https://docs.python.org/3/library/stdtypes.html#boolean-values) - Documentazione Ufficiale di Python - Il riferimento autorevole per il tipo bool di Python, che spiega come funzionano True e False, le operazioni booleane, e come Python valuta la truthiness nelle espressioni condizionali.

7. [Python Booleans](https://www.w3schools.com/python/python_booleans.asp) - W3Schools - Tutorial adatto ai principianti che copre il tipo bool, gli operatori di confronto, e come Python valuta le espressioni booleane, con esempi di codice interattivi "Try it Yourself" in tutto il testo.

8. [Python if...else Statement](https://www.programiz.com/python-programming/if-elif-else) - Programiz - Tutorial chiaro sulle istruzioni condizionali con esempi lavorati che combinano gli operatori and, or, e not dentro blocchi if/elif/else, ideale per studenti che costruiscono sulla conoscenza precedente delle condizioni semplici.

9. [Python Logical Operators](https://realpython.com/python-operators-expressions/#logical-operators) - Real Python - Spiegazione approfondita degli operatori and, or, e not con tavole di verità, regole di precedenza degli operatori, ed esempi di valutazione a corto circuito che approfondiscono la comprensione oltre l'uso booleano di base.

10. [Python Conditions and If statements](https://www.w3schools.com/python/python_conditions.asp) - W3Schools - Guida passo passo per scrivere condizioni con operatori di confronto e logici, con esempi di codice concisi che gli studenti possono eseguire e modificare per esplorare espressioni booleane complesse.
