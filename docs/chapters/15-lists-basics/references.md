# Riferimenti: Liste — Nozioni di Base

1. **[Python (programming language) — Wikipedia](https://en.wikipedia.org/wiki/Python_(programming_language))**
   Una panoramica enciclopedica del design, della storia, e delle strutture di dati fondamentali di Python, incluse le liste. Contesto utile per capire perché il tipo lista built-in di Python è così centrale per il linguaggio.

2. **[Array data structure — Wikipedia](https://en.wikipedia.org/wiki/Array_data_structure)**
   Spiega il concetto di collezioni ordinate e indicizzate che sono alla base delle strutture simili a liste nella programmazione. Aiuta gli studenti a collegare le liste Python all'idea più ampia di sequenze usate in tutti i linguaggi.

3. **[Dynamic array — Wikipedia](https://en.wikipedia.org/wiki/Dynamic_array)**
   Descrive come le collezioni ridimensionabili e mutabili sono implementate internamente. Supporta la discussione del capitolo sulla mutabilità e sul perché le liste Python possono crescere e cambiare mentre le stringhe no.

4. **Python Crash Course** di Eric Matthes (No Starch Press)
   Il Capitolo 3 fornisce un'introduzione adatta ai principianti alla creazione di liste, all'accesso agli elementi per indice, e alla modifica del contenuto delle liste — direttamente allineata con gli argomenti centrali di questo capitolo.

5. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Usa esempi giocosi per introdurre liste, indicizzazione, e slicing ai lettori più giovani. Lettura supplementare ideale per studenti dai 10 ai 13 anni che vogliono esercitarsi di più sulle basi delle liste a un livello accessibile.

6. **[Python Docs — Lists](https://docs.python.org/3/tutorial/introduction.html#lists)**
   La sezione del tutorial ufficiale di Python sulle liste copre i letterali delle liste, l'indicizzazione, lo slicing, e la mutabilità con esempi concisi. Il riferimento autorevole per ogni caratteristica introdotta in questo capitolo.

7. **[Real Python — Python Lists and Tuples](https://realpython.com/python-list/)**
   Una guida completa e ricca di esempi per creare e manipolare le liste Python, incluso l'indicizzazione, lo slicing, e la funzione `len()`. Eccellente lettura di approfondimento per studenti che vogliono spiegazioni più profonde.

8. **[W3Schools — Python Lists](https://www.w3schools.com/python/python_lists.asp)**
   Tutorial interattivi con esempi dal vivo che coprono la creazione di liste, l'indicizzazione, lo slicing, e la funzione `len()`. L'editor try-it permette agli studenti di sperimentare immediatamente, rafforzando l'approccio pratico del capitolo.

9. **[Programiz — Python List](https://www.programiz.com/python-programming/list)**
   Tutorial ben strutturati sui letterali delle liste, l'indicizzazione (inclusi gli indici negativi), lo slicing, e la mutabilità. Include diagrammi visivi che aiutano gli studenti a visualizzare come le posizioni degli indici corrispondono agli elementi della lista.

10. **[GeeksforGeeks — Python List](https://www.geeksforgeeks.org/python-lists/)**
    Articoli approfonditi che coprono la creazione di liste, l'accesso per indice, la sintassi di slicing, `len()`, e l'operatore `in`. Fornisce molti esempi di codice brevi adatti a studenti che vogliono vedere ogni concetto usato in contesti vari.
