# Riferimenti: Metodi delle Stringhe e Formattazione

1. **[String (computer science)](https://en.wikipedia.org/wiki/String_(computer_science))** — Articolo di Wikipedia che spiega cosa sono le stringhe nella programmazione, come memorizzano sequenze di caratteri, e perché sono uno dei tipi di dati più fondamentali in tutti i linguaggi di programmazione.

2. **[String interpolation](https://en.wikipedia.org/wiki/String_interpolation)** — Articolo di Wikipedia che copre le tecniche di interpolazione delle stringhe, incluse le f-string in Python, spiegando come le variabili e le espressioni possono essere incorporate direttamente dentro i letterali di stringa per un output pulito e leggibile.

3. **[Comparison of programming languages (string functions)](https://en.wikipedia.org/wiki/Comparison_of_programming_languages_(string_functions))** — Riferimento di Wikipedia che mostra come le operazioni comuni sulle stringhe come split, join, replace, e la conversione di maiuscole/minuscole sono implementate in linguaggi diversi, fornendo contesto per l'approccio di Python.

4. **Python Crash Course** di Eric Matthes (No Starch Press) — Il Capitolo 2 e le sezioni correlate coprono i metodi delle stringhe di Python incluso `upper()`, `lower()`, `strip()`, e le f-string, con esempi adatti ai principianti ideali per studenti nuovi alla manipolazione del testo.

5. **Python for Kids** di Jason R. Briggs (No Starch Press) — Un'introduzione accessibile a Python pensata per giovani studenti che copre le operazioni sulle stringhe, la formattazione, e i metodi built-in con esempi brevi e giocosi adatti per studenti dai 10 ai 13 anni.

6. **[Python String Methods — Official Docs](https://docs.python.org/3/library/stdtypes.html#string-methods)** — Il riferimento autorevole che elenca ogni metodo di stringa built-in in Python, incluso `upper`, `lower`, `strip`, `replace`, `split`, e `join`, con descrizioni precise ed esempi di utilizzo.

7. **[Python f-strings — Real Python](https://realpython.com/python-f-strings/)** — Un tutorial approfondito sulle f-string di Python (letterali di stringa formattati), che spiega la sintassi, l'incorporazione di espressioni, la formattazione di numeri e valori, e perché le f-string sono l'approccio moderno preferito alla formattazione delle stringhe.

8. **[Python Strings — W3Schools](https://www.w3schools.com/python/python_strings.asp)** — Un riferimento interattivo per principianti che copre le basi delle stringhe Python, l'indicizzazione, lo slicing, e tutti i principali metodi delle stringhe, con esempi di codice modificabili nel browser che rafforzano i concetti di questo capitolo.

9. **[Python String Methods — Programiz](https://www.programiz.com/python-programming/methods/string)** — Un catalogo ben organizzato dei metodi delle stringhe Python con spiegazioni chiare ed esempi provabili per ogni metodo, rendendolo un eccellente riferimento rapido mentre si pratica `split`, `join`, `strip`, e `replace`.

10. **[Python Strings — GeeksforGeeks](https://www.geeksforgeeks.org/python-strings/)** — Una guida completa alle stringhe Python che copre la creazione, l'indicizzazione, i metodi comuni, e le tecniche di formattazione delle stringhe, con molteplici esempi di codice che completano gli esercizi pratici di questo capitolo.
