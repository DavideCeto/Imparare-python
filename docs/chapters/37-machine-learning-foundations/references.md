# Riferimenti: Fondamenti di Machine Learning

1. **Machine Learning** — Wikipedia
   [https://en.wikipedia.org/wiki/Machine_learning](https://en.wikipedia.org/wiki/Machine_learning)
   Una panoramica ampia del machine learning, che copre l'apprendimento supervisionato e non supervisionato, l'allenamento dei modelli, e le applicazioni nel mondo reale. Un punto di partenza essenziale per capire come i computer imparano dai dati.

2. **Supervised Learning** — Wikipedia
   [https://en.wikipedia.org/wiki/Supervised_learning](https://en.wikipedia.org/wiki/Supervised_learning)
   Spiega come l'apprendimento supervisionato usa dati di training etichettati per insegnare ai modelli a classificare gli input o predire i valori. Direttamente rilevante per la trattazione di questo capitolo sui compiti di classificazione e regressione.

3. **Feature (Machine Learning)** — Wikipedia
   [https://en.wikipedia.org/wiki/Feature_(machine_learning)](https://en.wikipedia.org/wiki/Feature_(machine_learning))
   Descrive cosa sono le feature in un dataset e perché scegliere le feature giuste è importante per l'accuratezza del modello. Supporta l'introduzione del capitolo a come le macchine rappresentano e interpretano le informazioni sul mondo.

4. **Python Crash Course** di Eric Matthes (No Starch Press, 3ª ed.)
   I capitoli su dati e liste costruiscono le basi necessarie per organizzare i dati di training e gli insiemi di feature in Python, rendendo questo libro un compagno pratico per studenti che iniziano a lavorare con dataset strutturati.

5. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Scritto per la stessa fascia di età di questo manuale, introduce le strutture di dati e le funzioni Python in uno stile giocoso che facilita la transizione da Scratch al tipo di pensiero basato su liste che il machine learning richiede.

6. **scikit-learn: Getting Started** — Real Python
   [https://realpython.com/machine-learning-with-python/](https://realpython.com/machine-learning-with-python/)
   Un percorso adatto ai principianti per costruire e valutare modelli di machine learning in Python. Copre i dati di training, le etichette, e i concetti di valutazione dei modelli introdotti in questo capitolo con esempi di codice funzionanti.

7. **Python Lists Tutorial** — W3Schools
   [https://www.w3schools.com/python/python_lists.asp](https://www.w3schools.com/python/python_lists.asp)
   Le liste sono la struttura principale per memorizzare feature ed etichette nei programmi ML per principianti. Questa pagina fornisce esempi chiari e interattivi per creare, indicizzare, e iterare sulle liste che contengono i dati di training.

8. **Python Machine Learning Introduction** — GeeksforGeeks
   [https://www.geeksforgeeks.org/machine-learning/](https://www.geeksforgeeks.org/machine-learning/)
   Copre i concetti fondamentali incluso l'apprendimento supervisionato contro quello non supervisionato, la classificazione, e la regressione con diagrammi e codice. Un riferimento affidabile per studenti che vogliono una seconda spiegazione di qualsiasi termine di questo capitolo.

9. **Python for Loop** — Programiz
   [https://www.programiz.com/python-programming/for-loop](https://www.programiz.com/python-programming/for-loop)
   Iterare sui dataset di training è una delle prime competenze necessarie nel machine learning. Questo tutorial spiega i cicli for con esempi chiari che si applicano direttamente all'elaborazione di liste di feature ed etichette.

10. **Introduction to Python** — Khan Academy Computing
    [https://www.khanacademy.org/computing/intro-to-python-fundamentals](https://www.khanacademy.org/computing/intro-to-python-fundamentals)
    Un corso Python interattivo e autogestito che copre variabili, tipi di dati, e funzioni — i blocchi costitutivi di cui gli studenti hanno bisogno prima di scrivere i loro primi programmi di machine learning in Python.
