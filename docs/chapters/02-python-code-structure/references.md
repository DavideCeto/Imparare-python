# Riferimenti: Struttura del Codice Python

1. **[Python (linguaggio di programmazione) — Wikipedia](https://en.wikipedia.org/wiki/Python_(programming_language))**
   Una panoramica della storia di Python, della filosofia di progettazione e dei principi di sintassi. Copre perché i creatori di Python hanno prioritizzato la leggibilità del codice pulito con spazi significativi e indentazione coerente

2. **[Indentazione (programmazione) — Wikipedia](https://en.wikipedia.org/wiki/Indentation_(programming))**
   Spiega come l'indentazione viene utilizzata nei linguaggi di programmazione per indicare blocchi di codice. Particolarmente rilevante qui perché Python utilizza l'indentazione come sintassi effettiva — non solo stile — per definire

3. **[Parola riservata — Wikipedia](https://en.wikipedia.org/wiki/Reserved_word)**
   Descrive parole chiave e parole riservate nei linguaggi di programmazione. Direttamente rilevante all'insieme di parole chiave Python come `if`, `for`, `while` e `def`, che non possono essere usate come nomi di variabili e

4. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Scritto per giovani studenti, questo libro introduce la sintassi Python, l'indentazione e la struttura del codice con umorismo e esempi visivi. Corrisponde strettamente al pubblico di questo capitolo di studenti dai 10 ai 1

5. **Python Crash Course** di Eric Matthes (No Starch Press)
   Un popolare libro Python da principiante a intermedio che copre le regole di sintassi, l'indentazione corretta e la leggibilità del codice nei suoi capitoli iniziali. Lettura supplementare utile per studenti che vogliono una spiegazione approfondita

6. **[Python Official Docs — Lexical Analysis](https://docs.python.org/3/reference/lexical_analysis.html)**
   Il riferimento autoritativo per la grammatica di Python, le parole chiave, le regole di indentazione e la gestione dello spazio bianco. Spiega esattamente come Python analizza la struttura del codice — fondamentale per capire perché

7. **[W3Schools — Python Syntax](https://www.w3schools.com/python/python_syntax.asp)**
   Una spiegazione concisa e adatta ai principianti della sintassi Python inclusi indentazione, commenti e blocchi di codice. Include esempi interattivi "Provalo Tu Stesso" che consentono agli studenti di sperimentare la struttura del codice

8. **[Real Python — Python Keywords](https://realpython.com/python-keywords/)**
   Una guida completa a ogni parola chiave Python con spiegazioni in linguaggio semplice e esempi. Aiuta gli studenti a capire quali parole Python riserva per la sua stessa grammatica e perché non possono essere usate come

9. **[Programiz — Python Indentation](https://www.programiz.com/python-programming/statement-indentation-comments)**
   Spiega le istruzioni Python, l'indentazione e i commenti con esempi chiari e diagrammi. Copre direttamente le regole che Python applica per i blocchi di codice, rendendolo lettura ideale insieme a questo capitolo
