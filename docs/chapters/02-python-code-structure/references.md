# Riferimenti: Struttura del Codice Python

1. **[Python (programming language) — Wikipedia](https://en.wikipedia.org/wiki/Python_(programming_language))**
   Una panoramica sulla storia di Python, la sua filosofia di design e i principi di sintassi. Spiega perché i creatori di Python hanno dato priorità a una struttura del codice leggibile e ordinata, con spazi bianchi significativi e indentazione coerente come caratteristiche fondamentali del linguaggio.

2. **[Indentation (programming) — Wikipedia](https://en.wikipedia.org/wiki/Indentation_(programming))**
   Spiega come l'indentazione viene usata nei vari linguaggi di programmazione per indicare i blocchi di codice. Particolarmente rilevante qui perché Python usa l'indentazione come vera sintassi — non solo come stile — per definire la struttura dei programmi.

3. **[Reserved word — Wikipedia](https://en.wikipedia.org/wiki/Reserved_word)**
   Descrive le parole chiave e le parole riservate nei linguaggi di programmazione. Direttamente rilevante per l'insieme di parole chiave di Python come `if`, `for`, `while` e `def`, che non possono essere usate come nomi di variabili e definiscono la grammatica di Python.

4. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Scritto per studenti più giovani, questo libro introduce la sintassi di Python, l'indentazione e la struttura del codice con umorismo ed esempi visivi. Corrisponde molto bene al pubblico di questo capitolo: studenti di 10-13 anni nuovi alla programmazione testuale.

5. **Python Crash Course** di Eric Matthes (No Starch Press)
   Un popolare libro Python da principiante a intermedio che copre le regole di sintassi, l'indentazione corretta e la leggibilità del codice nei suoi primi capitoli. Lettura supplementare utile per studenti che vogliono un'introduzione approfondita e ricca di esempi alla struttura di Python.

6. **[Python Official Docs — Lexical Analysis](https://docs.python.org/3/reference/lexical_analysis.html)**
   Il riferimento ufficiale per la grammatica di Python, le parole chiave, le regole di indentazione e la gestione degli spazi bianchi. Spiega esattamente come Python analizza la struttura del codice — fondamentale per capire perché esistono queste regole di sintassi.

7. **[W3Schools — Python Syntax](https://www.w3schools.com/python/python_syntax.asp)**
   Una spiegazione concisa e adatta ai principianti della sintassi Python, inclusi indentazione, commenti e blocchi di codice. Include esempi interattivi "Try it Yourself" che permettono agli studenti di sperimentare la struttura direttamente nel browser.

8. **[Real Python — Python Keywords](https://realpython.com/python-keywords/)**
   Una guida completa a ogni parola chiave di Python con spiegazioni in linguaggio semplice ed esempi. Aiuta gli studenti a capire quali parole Python riserva per la propria grammatica e perché non possono essere usate come nomi di variabili.

9. **[Programiz — Python Indentation](https://www.programiz.com/python-programming/statement-indentation-comments)**
   Spiega gli statement, l'indentazione e i commenti in Python con esempi e diagrammi chiari. Copre direttamente le regole che Python impone per i blocchi di codice, rendendola una lettura ideale in parallelo al contenuto di questo capitolo.

10. **[CS Circles — Python Indentation and Blocks](https://cscircles.cemc.uwaterloo.ca/4-if/)**
    Un corso Python interattivo basato su browser dell'Università di Waterloo. Questa unità si concentra su condizioni e blocchi di codice indentati, permettendo agli studenti di esercitarsi a strutturare correttamente il codice con feedback immediato nel browser.
