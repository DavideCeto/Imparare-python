# Riferimenti: Libreria Standard e JSON

1. **[JSON](https://en.wikipedia.org/wiki/JSON)** — Wikipedia.
   Spiega il formato di dati JSON (JavaScript Object Notation), la sua storia, struttura, e l'uso diffuso nelle API web e nello scambio di dati. Copre i concetti chiave di oggetti, array, stringhe, e numeri che corrispondono direttamente ai tipi di dati Python.

2. **[Python Standard Library](https://en.wikipedia.org/wiki/Python_Standard_Library)** — Wikipedia.
   Fornisce una panoramica della Libreria Standard di Python, descrivendo la grande collezione di moduli built-in disponibili senza installazione. Spiega come moduli come `os`, `sys`, e `json` danno ai programmi Python potenti capacità già pronte.

3. **[Serialization](https://en.wikipedia.org/wiki/Serialization)** — Wikipedia.
   Copre il concetto di convertire strutture di dati in un formato memorizzabile o trasmissibile, che è esattamente ciò che fanno `json.dumps` e `json.loads`. Aiuta gli studenti a capire perché JSON è così comunemente usato per salvare e condividere i dati Python.

4. **Python Crash Course** di Eric Matthes (No Starch Press).
   Il Capitolo 10 copre il lavoro con i file e i formati di dati incluso JSON, mostrando `json.dumps` e `json.loads` con progetti pratici che gli studenti principianti possono seguire passo passo.

5. **Automate the Boring Stuff with Python** di Al Sweigart (No Starch Press; gratuito online su automatetheboringstuff.com).
   Usa i moduli `os`, `sys`, e `json` in tutti i progetti di automazione del mondo reale, mostrando agli studenti esattamente come i moduli della Libreria Standard semplificano i compiti di programmazione quotidiani come leggere file ed elaborare dati.

6. **[Python json Module — Official Documentation](https://docs.python.org/3/library/json.html)** — docs.python.org.
   Il riferimento autorevole per il modulo `json`, che copre `json.loads`, `json.dumps`, la codifica, la decodifica, e le opzioni di formattazione. Lettura essenziale per capire ogni parametro e comportamento delle funzioni insegnate in questo capitolo.

7. **[Working With JSON Data in Python](https://realpython.com/python-json/)** — realpython.com.
   Un tutorial adatto ai principianti che percorre la lettura e la scrittura di JSON con Python, incluso la conversione tra stringhe JSON e dizionari Python. Include esempi chiari di `json.loads` e `json.dumps` con spiegazioni utili.

8. **[Python JSON](https://www.w3schools.com/python/python_json.asp)** — w3schools.com.
   Un'introduzione concisa e pratica al modulo `json` di Python con esempi provabili che mostrano come analizzare stringhe JSON in oggetti Python e convertire i dati Python di nuovo in formato JSON.

9. **[Python os Module](https://www.programiz.com/python-programming/os-module)** — programiz.com.
   Copre il modulo `os` con esempi chiari che mostrano come lavorare con i percorsi dei file, elencare le cartelle, e interagire con il sistema operativo. Aiuta gli studenti a vedere come la Libreria Standard estende le capacità built-in di Python.

10. **[Python JSON Module](https://www.geeksforgeeks.org/python-json/)** — geeksforgeeks.org.
    Spiega l'analisi e la generazione di JSON in Python con esempi lavorati che coprono `json.loads`, `json.dumps`, la formattazione leggibile con `indent`, e casi d'uso comuni per memorizzare e caricare dati nei progetti degli studenti.
