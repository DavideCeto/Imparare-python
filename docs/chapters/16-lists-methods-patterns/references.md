# Riferimenti: Liste — Metodi e Pattern

1. **[Python (programming language) — Wikipedia](https://en.wikipedia.org/wiki/Python_(programming_language))**
   La panoramica di Wikipedia su Python copre la filosofia di design del linguaggio e le strutture di dati built-in, incluse le liste. Un buon punto di partenza per capire perché le liste sono una caratteristica centrale di Python.

2. **[List (abstract data type) — Wikipedia](https://en.wikipedia.org/wiki/List_(abstract_data_type))**
   Spiega cos'è una lista come struttura di dati fondamentale dell'informatica, coprendo operazioni come l'inserimento, la rimozione, e l'attraversamento. Aiuta gli studenti a capire i concetti dietro i metodi delle liste di Python.

3. **[Sorting algorithm — Wikipedia](https://en.wikipedia.org/wiki/Sorting_algorithm)**
   Descrive come funzionano gli algoritmi di ordinamento e perché l'ordinamento è un'operazione fondamentale nell'informatica. Rilevante per capire cosa fanno internamente i metodi `sort()` e `reverse()` di Python.

4. **Python Crash Course** di Eric Matthes (No Starch Press)
   I Capitoli 3 e 4 coprono le liste Python a fondo, incluso `append()`, `insert()`, `remove()`, `pop()`, l'ordinamento, e il ciclo attraverso le liste — corrispondendo direttamente ai concetti di questo capitolo.

5. **Python for Kids** di Jason R. Briggs (No Starch Press)
   Scritto per giovani studenti, questo libro introduce la creazione di liste e i metodi comuni con esempi giocosi. Lettura supplementare ideale per studenti dai 10 ai 13 anni che affrontano le operazioni sulle liste per la prima volta.

6. **[Python Docs — Data Structures: Lists](https://docs.python.org/3/tutorial/datastructures.html)**
   La sezione del tutorial ufficiale di Python sulle liste documenta ogni metodo di lista built-in incluso `append()`, `insert()`, `remove()`, `pop()`, `sort()`, e `reverse()` con esempi concisi e autorevoli.

7. **[Real Python — Python Lists and List Methods](https://realpython.com/python-list/)**
   Una guida completa su come creare, modificare, e iterare sulle liste Python. Include spiegazioni chiare delle list comprehension e dei pattern comuni delle liste usati in questo capitolo.

8. **[W3Schools — Python Lists](https://www.w3schools.com/python/python_lists.asp)**
   Un riferimento interattivo che copre la creazione delle liste, l'indicizzazione, i metodi, e il ciclo. Gli studenti possono eseguire esempi direttamente nel browser, rendendo facile sperimentare con `append()`, `sort()`, e altri metodi.

9. **[Programiz — Python List Methods](https://www.programiz.com/python-programming/methods/list)**
   Una pagina di riferimento chiara che elenca ogni metodo di lista Python con sintassi, parametri, ed esempi. Utile per cercare velocemente come funzionano `insert()`, `remove()`, `pop()`, e `reverse()` durante gli esercizi.

10. **[GeeksforGeeks — Python List Comprehension](https://www.geeksforgeeks.org/python-list-comprehension/)**
    Spiega la sintassi delle list comprehension passo passo con molteplici esempi, mostrando come creano nuove liste da quelle esistenti in una singola riga leggibile — un pattern chiave introdotto in questo capitolo.
