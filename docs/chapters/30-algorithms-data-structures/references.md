# Riferimenti: Algoritmi e Strutture Dati

1. **Wikipedia: Algorithm** — [https://en.wikipedia.org/wiki/Algorithm](https://en.wikipedia.org/wiki/Algorithm)
   Una panoramica fondamentale di cosa sono gli algoritmi, come funzionano, e perché sono importanti. Copre il design degli algoritmi, la correttezza, e la complessità — direttamente rilevante per il tema centrale di questo capitolo.

2. **Wikipedia: Data Structure** — [https://en.wikipedia.org/wiki/Data_structure](https://en.wikipedia.org/wiki/Data_structure)
   Spiega come le pile, le code, i grafi, e altre strutture di dati organizzano le informazioni in memoria. Fornisce il contesto essenziale per capire perché scegliere la struttura giusta è importante per un dato problema.

3. **Wikipedia: Breadth-First Search** — [https://en.wikipedia.org/wiki/Breadth-first_search](https://en.wikipedia.org/wiki/Breadth-first_search)
   Descrive l'algoritmo di attraversamento di grafi BFS con diagrammi e pseudocodice. Contesto essenziale per gli studenti che imparano come BFS e DFS esplorano i nodi in un grafo usando code contro pile.

4. **Python Crash Course** di Eric Matthes (No Starch Press)
   Introduce le strutture di dati Python e il controllo di flusso con esempi chiari e basati su progetti. I capitoli su liste e dizionari costruiscono le basi di cui gli studenti hanno bisogno per implementare pile, code, e liste di adiacenza in Python.

5. **Think Python** di Allen B. Downey (O'Reilly, gratuito online su greenteapress.com/thinkpython)
   Un'introduzione rigorosa ma leggibile al pensiero computazionale, al design degli algoritmi, e alla ricorsione. Copre direttamente l'ordinamento, la ricerca, e l'analisi della complessità a una profondità appropriata per studenti che vanno oltre la programmazione a blocchi.

6. **Python Docs — modulo `collections`** — [https://docs.python.org/3/library/collections.html](https://docs.python.org/3/library/collections.html)
   Riferimento ufficiale per `deque`, una struttura built-in di Python ideale per implementare pile e code efficientemente. Mostra esempi concreti di come fare push, pop, e peek usando gli strumenti della libreria standard.

7. **Real Python: Introduction to Stacks and Queues** — [https://realpython.com/queue-in-python/](https://realpython.com/queue-in-python/)
   Un tutorial pratico che percorre le implementazioni Python delle code usando liste, `deque`, e il modulo `queue`. Include visualizzazioni ed esempi lavorati che rafforzano i concetti di pila e coda di questo capitolo.

8. **Programiz: BFS and DFS in Python** — [https://www.programiz.com/dsa/graph-bfs](https://www.programiz.com/dsa/graph-bfs)
   Spiegazione passo passo della ricerca in ampiezza con diagrammi animati e codice Python completo. Aiuta i principianti a vedere esattamente come BFS attraversa un grafo livello per livello usando una coda.

9. **GeeksforGeeks: Sorting Algorithms in Python** — [https://www.geeksforgeeks.org/sorting-algorithms-in-python/](https://www.geeksforgeeks.org/sorting-algorithms-in-python/)
   Copre il bubble sort, il selection sort, il merge sort, e altro con implementazioni Python e confronti di complessità. Un riferimento utile per studenti che esplorano perché diversi algoritmi di ordinamento hanno velocità diverse su grandi insiemi di dati.

10. **W3Schools: Python Binary Search** — [https://www.w3schools.com/python/python_binarysearch.asp](https://www.w3schools.com/python/python_binarysearch.asp)
    Una spiegazione adatta ai principianti della ricerca binaria con esempi di codice interattivi. Mostra agli studenti come cercare in una lista ordinata dimezzandola sia drammaticamente più veloce che scansionare ogni elemento uno alla volta.
