# Riferimenti: Lavorare con le Stringhe

1. **String (computer science)** — Wikipedia.
   [https://en.wikipedia.org/wiki/String_(computer_science)](https://en.wikipedia.org/wiki/String_(computer_science))
   Spiega cosa sono le stringhe nell'informatica, come vengono memorizzate, e perché sono uno dei tipi di dati fondamentali presenti in ogni linguaggio di programmazione, incluso Python.

2. **String literal** — Wikipedia.
   [https://en.wikipedia.org/wiki/String_literal](https://en.wikipedia.org/wiki/String_literal)
   Copre il concetto di scrivere valori stringa direttamente nel codice sorgente usando le virgolette, inclusa la differenza tra letterali con virgolette singole e doppie nei vari linguaggi.

3. **Escape character** — Wikipedia.
   [https://en.wikipedia.org/wiki/Escape_character](https://en.wikipedia.org/wiki/Escape_character)
   Descrive come le sequenze di escape come `\n` e `\t` permettono ai programmatori di inserire caratteri speciali dentro le stringhe, un concetto chiave introdotto in questo capitolo.

4. **Python Crash Course** di Eric Matthes (No Starch Press, 2023).
   Il Capitolo 2 copre in profondità le stringhe Python, inclusi concatenazione, metodi e formattazione, rendendolo un ottimo complemento per studenti che vogliono esempi ed esercizi aggiuntivi.

5. **Python for Kids** di Jason R. Briggs (No Starch Press, 2013).
   Scritto specificamente per giovani studenti, questo libro introduce le stringhe con esempi adatti all'età e umorismo, corrispondendo da vicino al pubblico e allo stile didattico di questo capitolo.

6. **Python Docs — Built-in String Methods**
   [https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str](https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str)
   Il riferimento ufficiale di Python per il tipo `str`, che elenca ogni metodo integrato con descrizioni precise; la fonte autorevole per capire `len()` e il comportamento dell'indicizzazione delle stringhe.

7. **Real Python — Python String Formatting**
   [https://realpython.com/python-strings/](https://realpython.com/python-strings/)
   Un tutorial approfondito e adatto ai principianti che copre letterali stringa, concatenazione, indicizzazione, slicing e caratteri di escape con esempi interattivi direttamente rilevanti per questo capitolo.

8. **W3Schools — Python Strings**
   [https://www.w3schools.com/python/python_strings.asp](https://www.w3schools.com/python/python_strings.asp)
   Fornisce esempi concisi ed eseguibili per ogni concetto fondamentale sulle stringhe — letterali, concatenazione, `len()`, indicizzazione e caratteri di escape — con un editor "Try it Yourself" integrato.

9. **Programiz — Python Strings**
   [https://www.programiz.com/python-programming/string](https://www.programiz.com/python-programming/string)
   Copre i fondamenti delle stringhe Python con diagrammi chiari che mostrano come vengono indicizzati i caratteri, più brevi programmi che gli studenti possono eseguire immediatamente per rafforzare la comprensione.

10. **Khan Academy — Intro to Python Fundamentals: Strings**
    [https://www.khanacademy.org/computing/intro-to-python-fundamentals/x5fcf6ce9534777be:strings](https://www.khanacademy.org/computing/intro-to-python-fundamentals/x5fcf6ce9534777be:strings)
    Una sequenza interattiva di video ed esercizi pensata per principianti, che percorre la creazione di stringhe, la concatenazione e le operazioni di base a un ritmo adatto a studenti dai 10 ai 13 anni.
