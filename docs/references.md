# Riferimenti per Learning Python

## Imparare Python su Raspberry Pi

- [Raspberry Pi Foundation Projects](https://projects.raspberrypi.org/en)

- [Raspberry Pi CoderDojo Projects](https://projects.raspberrypi.org/en/coderdojo)

- [Thonny](https://thonny.org/) Thonny è un ambiente di sviluppo integrato (IDE) per il debug del codice Python. Purtroppo non supporta le grafiche turtle.

- [Adafruit CircuitPython](https://learn.adafruit.com/welcome-to-circuitpython/what-is-circuitpython) CircuitPython è un linguaggio di programmazione progettato per semplificare la sperimentazione e l'apprendimento della programmazione su microcontrollori economici.

- [Learning Python with Raspberry Pi Book](https://www.raspberrypi.org/blog/learning-python-with-raspberry-pi/)

- [Sparkfun Tutorial](https://learn.sparkfun.com/tutorials/python-programming-tutorial-getting-started-with-the-raspberry-pi/all)

- [Controlling LED Strips with Python](https://tutorials-raspberrypi.com/connect-control-raspberry-pi-ws2812-rgb-led-strips/)
